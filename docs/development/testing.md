# Testing

## Repository checks

Python 3.11+:

```sh
python3 tools/repo_check.py
git diff --check
```

The checker validates required entry points, local Markdown/image links, dependency metadata, submodule pins and accidental inclusion of local/private files. It does not certify every historical commit or replace a secret scanner.

## Android checks

```sh
./gradlew --no-daemon :app:assembleDebug :app:lintDebug :app:testDebugUnitTest -PtargetAbi=armeabi-v7a
```

The geometry tests cover portrait sizing, longest-edge preservation, screen bounds and legacy width conversion. Lint warnings remain in the inherited app; successful lint is not equivalent to zero warnings. Native builds require initialized submodules.

## Browser fixtures

Node 20+:

```sh
npm ci --prefix tools
npm run browsers --prefix tools
npm test --prefix tools
```

On a Linux CI host, install browser system dependencies with:

```sh
npm exec --prefix tools -- playwright install --with-deps chromium webkit
```

The suite uses its own loopback HTTP fixture, Chromium and WebKit. It never contacts a TV. Reports and screenshots are written under ignored artifacts/web-smoke in the repository working directory.

Optional environment variables:

| Variable | Purpose |
| --- | --- |
| CHROME_EXECUTABLE | Use a separately installed Chrome for the Chromium run |
| PLAYWRIGHT_BROWSERS_PATH | Use a chosen Playwright browser cache |
| PLAYWRIGHT_MODULE | Advanced override of the Playwright module location |
| QA_OUT | Choose the output report/screenshot directory |

The shipped web assets have no Node runtime dependency. Browser tests establish interaction, layout and state synchronization, not audible audio or visible hardware composition.

## Optional device diagnostics

Install the host-only ADB dependencies in an ignored virtual environment:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r tools/requirements-device.txt
```

The ADB tools use the operator's existing ~/.android/adbkey and its public key; authorize that computer on the target device. No key is shipped or generated by these scripts. Replace TV_IP and TV_MODEL below with an explicitly selected test device.

Read-only audio inventory:

```sh
.venv/bin/python tools/inspect_tv_audio.py --host TV_IP --expected-model TV_MODEL
```

HTTP smoke checks mutate only this app's controls and restore saved settings. Run them when no mirroring session is active:

```sh
python3 tools/remote_smoke.py --url http://TV_IP:8765
```

The legacy ADB smoke script can install an APK, change overlay permission and this app's settings, open its control Activity, take screenshots and stop/start reception. Its full path is intentionally interactive with the device:

```sh
.venv/bin/python tools/device_smoke.py --help
```

Read its arguments before use. --compact-only avoids opening the Activity but still changes this app's settings. It is not a read-only test. Do not run device scripts as ordinary CI or against an active household TV.

Hardware acceptance should record TV firmware, sender version, input and output route, actual picture/audio observations, and disconnect behavior. A simulated quick-boot event is not a power-cycle test. See [existing evidence](../validation/README.md).
