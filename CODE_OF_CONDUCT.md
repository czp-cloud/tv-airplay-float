# Community conduct

Treat contributors and users with respect. Discuss code and behavior with concrete evidence; avoid personal attacks, harassment, discrimination, threats and disclosure of private information.

Use issues and pull requests for project work. Do not upload personal media, device identifiers or credentials. Respect requests to move a sensitive discussion to a private channel.

Repository maintainers may edit or remove material and restrict participation to keep discussions useful and safe. For a private concern, contact the repository owner through the host's private contact mechanism. Vulnerabilities follow [SECURITY.md](SECURITY.md).
